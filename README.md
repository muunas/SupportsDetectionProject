# Support Detection Project

Proyecto personal desarrollado para analizar activos financieros y detectar **soportes relevantes** en gráficos de velas semanales.  
El objetivo es construir un **screener automático** que:

- Descargue datos históricos semanales de cada ticker.
- Identifique soportes mediante pivotes mínimos.
- Calcule la distancia porcentual entre el precio actual y cada soporte.
- Filtre los soportes más cercanos según un porcentaje máximo.
- Muestre resultados de forma clara en la terminal.

Este proyecto sirve como base para futuros análisis técnicos automatizados y como práctica real de:
- Python aplicado a mercados financieros  
- YahooQuery para extracción de datos  
- Procesamiento de series temporales  
- Arquitectura modular de proyectos  
- Uso profesional de Git y GitHub
